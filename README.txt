1. Создай на github.com новый ПУБЛИЧНЫЙ репозиторий и загрузи в него все файлы из этой папки
   (включая скрытую папку .github).
2. Вкладка Actions -> Build IPA -> дождись зелёной галочки (5-10 минут).
3. Внутри запуска скачай артефакт Pary-ipa, распакуй, получишь Pary.ipa.
4. Установи AltServer на ПК, поставь AltStore на айфон, затем в AltStore: My Apps -> + -> выбери Pary.ipa.
5. Добавь виджет "Пары" на экран, в приложении внеси расписание.
